## 11. Technical Notes

### Slide Installation (GTV H53)
- **Gap:** 19.0±0.5mm between slide and cabinet wall (critical!)
- **Screws:** Flat-head M5×10 (not included), 16 per pair (32 total)
- **Unfastening:** Lever release allows drawer removal without tools
- **Load:** 100kg/pair at 600mm — derate to 80kg for dynamic/camper use
- **Orientation:** Slides mounted vertically on 20×40 uprights via brackets

### Profile Cutting Tolerances
- Motedis: ±1mm length, ±0.2mm angle
- Dold: ±1mm length
- Specify: "Cut to length, deburred, no further machining"

### T-Nut Selection
- **Slot 6 (20×40):** M5 for brackets, M6 for core threads / heavy joints
- **Slot 8 (40×80, 70×90, U-profile):** M6 standard, M8 for high load
- All hammer nuts rotate 90° on tightening — breaks anodization for grounding

### Multiplex Edge Sealing
- Cut edges MUST be sealed with epoxy/varnish for outdoor/moisture resistance
- Use Sikaflex 291 or similar for screw holes

### Weight Budget (per module)
- Slides: 2× ~2.5kg = 5kg
- Profiles: ~14kg (17.8m × 0.78kg/m)
- U-profiles: ~3.5kg
- Brackets + hardware: ~2kg
- Multiplex: ~9kg (1.32m² × 6.8kg/m² @ 15mm birch)
- **Module empty weight: ~33kg each** — within T6 payload
